Политика конфиденциальности

Дата последнего обновления: 21 марта 2026 г.

1. Введение

Это приложение для управления термостатом (далее — "Приложение") уважает вашу конфиденциальность. Эта политика объясняет, какие данные мы собираем и как их используем для обеспечения работы приложения.

2. Какие данные мы собираем

Для подключения и управления вашим термостатом приложение запрашивает следующие разрешения и данные:

📍 Геоданные (Местоположение)

  • Зачем: На Android для сканирования Bluetooth-устройств и сетей Wi-Fi требуется разрешение на определение местоположения. Это техническое требование операционной системы.
  • Когда: Разрешение запрашивается только в момент подключения к термостату.
  • Как используются: Геоданные используются исключительно для обнаружения и подключения к вашему термостату. Они не отслеживаются, не сохраняются и не передаются на наши серверы или третьим лицам.
  • Важно: Как только подключение установлено, геоданные больше не используются.

📶 Bluetooth

  • Зачем: Для беспроводного подключения к термостату.
  • Какие данные: MAC-адрес термостата, имя устройства, сигнал Bluetooth.
  • Как используются: Только для установки и поддержания соединения с вашим термостатом. Данные хранятся локально на вашем устройстве.

📡 Wi-Fi

  • Зачем: Для подключения к термостату через локальную сеть (если термостат поддерживает Wi-Fi).
  • Какие данные: Название сети (SSID), IP-адрес (локальный).
  • Как используются: Только для подключения к термостату в вашей домашней сети. Данные не передаются за пределы вашего устройства.

⚙️ Другие данные

  • Данные устройства: Модель устройства, версия Android (для диагностики совместимости).
  • Настройки термостата: Температура, режимы работы — сохраняются только локально на вашем устройстве.

3. Как мы используем данные

  • ✅ Для обнаружения и подключения к вашему термостату (Bluetooth/Wi-Fi)
  • ✅ Для управления температурой и режимами работы
  • ✅ Для улучшения стабильности приложения (исправление ошибок)
  • ❌ Мы НЕ передаем геоданные, Bluetooth-данные или Wi-Fi-данные третьим лицам
  • ❌ Мы НЕ отслеживаем ваше местоположение после подключения
  • ❌ Мы НЕ продаем ваши данные

4. Разрешения Android

Приложение запрашивает следующие разрешения:

  • • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION — для сканирования Bluetooth и Wi-Fi устройств (требование Android). Используется ТОЛЬКО в момент подключения.
  • • BLUETOOTH / BLUETOOTH_SCAN / BLUETOOTH_CONNECT — для подключения к термостату по Bluetooth.
  • • ACCESS_WIFI_STATE / CHANGE_WIFI_STATE — для работы с Wi-Fi подключением термостата.

5. Хранение и безопасность данных

  • Все настройки термостата хранятся локально на вашем устройстве.
  • Мы не храним ваши данные на внешних серверах.
  • Геоданные используются только в момент подключения и не сохраняются.

6. Ваши права

  • Вы можете отозвать разрешения на местоположение, Bluetooth или Wi-Fi в настройках Android в любой момент.
  • Вы можете удалить все данные, связанные с приложением, просто удалив приложение с вашего устройства.
